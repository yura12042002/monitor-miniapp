# monitor-miniapp

Mini App «Цели» для Telegram-бота monitor. Статическая страница: список целей приходит в ссылке кнопки бота (часть после `#`, на сервер не уходит), правки возвращаются боту через `Telegram.WebApp.sendData`. Данных и ключей здесь нет.

Исходник — `apps/core/assets/miniapp.html` в основном (приватном) репозитории.
